Backup & restore

Download a copy of the database to keep safe. Restore from a previous backup if needed.

What gets backed up: every user, class, student, question, exam, score, attendance record and report card — the entire school database.

When restoring: the current database is replaced. A safety copy of your existing database is saved on the server as cbt.db.before-restore-… in case you need to roll back.

After restoring: stop the server (Ctrl + C) and run npm start again.
