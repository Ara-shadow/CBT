# Teacher guide

You manage the questions, exams, scores and attendance for the classes
you teach.

## Getting set up

Log in with the username and password your admin gave you.

You'll see the **Home** dashboard with links to:
- Question bank
- Exams
- Scores
- Attendance summary
- Daily attendance
- Results

## Day-to-day tasks

### 1. Creating questions

1. Click **Question bank**
2. Click **+ Add question**
3. Fill in the question, options, correct answer, marks
4. Save

You can also **import many questions at once** from a spreadsheet:

1. Click **Import CSV**
2. Prepare a CSV file with columns:
   `question, option_a, option_b, option_c, option_d, option_e, correct_answer, marks, subject, explanation`
3. Upload and check the report

### 2. Building an exam

1. Click **Exams** → **+ Create exam**
2. Fill in title, subject, class, session, term, duration, pass mark
3. Tick the questions you want to include
4. Save

An admin must **publish** the exam before students can see it.

### 3. Entering scores

1. Click **Scores**
2. Choose class, subject, session, term
3. Enter CA1 (out of 10), CA2 (out of 20), Project (out of 10), PBT (out of 30)
4. CBT scores are filled automatically when students take the CBT
5. Click **Save all**

If a student did a CBT, click **Sync CBT scores** to pull in their result.

### 4. Marking attendance

**Daily method** (recommended):
1. Click **Daily attendance**
2. Choose class, session, term, date
3. Click P or A next to each student
4. Click **Save day**

**Term summary method** (faster but less detailed):
1. Click **Attendance summary**
2. Enter days school opened and closed (once for the class)
3. Enter days present for each student
4. Click **Save attendance**

### 5. Viewing results

1. Click **Results**
2. Choose class, session, term
3. Switch between **Midterm** and **End of term** tabs
4. Click a student to see the full breakdown

## End-of-term checklist

- [ ] All CA1, CA2, Project scores entered for every student
- [ ] All PBT scores entered
- [ ] CBT results synced
- [ ] Attendance marked
- [ ] Verified totals look correct (spot-check a few)
- [ ] Reported any issues to admin
